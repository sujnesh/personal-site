## Overview

Attunedd is a backend for adaptive strength training. It models coaching, fatigue, and programming
logic so the user is not locked into a static plan that ignores how training is actually going.

## Core Ideas

- Periodization that adapts to recent training state.
- Fatigue-aware adjustments.
- Coaching logic that can explain the next step.

## Product Question

Can strength programming feel personal without requiring a human coach to manually rewrite every
week of training?
